1. Quick start (60 seconds)

  1. 1
    Open the app
    Local demo: http://localhost:4173 after pnpm --filter shell preview. Or double-click apps/shell/dist/index.html.
  2. 2
    Pick a tenant on the marketing page
    Choose Spice Route (F&B), Velvet (fashion), or La Maison (retail). Each is a fully seeded independent store.
  3. 3
    Log in as owner
    Owner credentials sit under Store → Users in every tenant. Or log in as a seeded cashier for the counter view.
  4. 4
    Confirm the outlet in the top-right picker
    Everything you do below is scoped to this outlet: menu, sales, staff PINs, kitchen tickets. Switch outlets from the same picker.
  5. 5
    Ring a sale
    Sidebar → Cashier. Add items, tap Charge, pick mode & payment, Confirm. Watch it appear in Sales, Live orders, Dashboard.

2. Roles — who does what

Vendor / HQ

Cross-store visibility. Owns markets, brands, and stores themselves. Sees chain-wide reports.

Owner

Runs one store. Creates outlets, hires staff, sets menu / products, defines recipes and suppliers.

Manager

Runs one outlet daily. Handles procurement (POs, GRNs), promotions (coupons), voids, reports.

Cashier

Front-of-house. PIN login, rings sales, takes payments, prints KOTs, closes shift.

Customer

Browses storefront (/:slug/store), places online orders, pays via gateway.

System

Auto-generated rows: audit log, invoice numbers, stock adjustments from recipes, EOD roll-ups.

6. The sale ripple — one action, seven effects

When a cashier taps Confirm on the checkout modal, this cascade fires. Every downstream box is automatic — nobody types them.

Cashier taps Confirm
1. sales row inserted with items[], payments[], outletId stamp
2. invoice_no minted from per-outlet sequence
3. KOT tickets pushed to relevant kotStations (KDS)
4. Stock decrement for every recipe ingredient
5. customerPayments & balance if Lending mode
6. Live-orders kanban + Dashboard KPIs re-render (live query)
and one final one, out-of-band
7. auditLog row: action=sale.recorded, actor, before/after
Why this matters: because #3–#6 are automatic and outlet-scoped, a cashier at Koramangala cannot accidentally push a KOT to Indiranagar's kitchen. Same code path, same scoping, no chance of cross-outlet leakage.
